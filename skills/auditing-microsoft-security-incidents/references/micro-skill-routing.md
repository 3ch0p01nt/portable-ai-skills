# Micro-Skill Routing

This routing table binds the root router to the installed incident-audit
micro-skills. Every branch remains read-only, returns evidence to the shared
kernel, and leaves report-level verdicts and determinations to root-kernel
synthesis.

## Boundary rules

Use `incident-audit-endpoint` for broad device triage across process, file,
network, registry, logon, device, and source-host evidence. Use
`incident-audit-windows-forensics` for deep process identity, artifact semantics
and host timeline reconstruction. Use `incident-audit-persistence-lateral` for
cross-domain persistence anchors and movement edges that connect host, identity,
cloud, mailbox, and network evidence.
